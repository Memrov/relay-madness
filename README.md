# Relay Madness

A thin universal relay for provider-hosted coding agents, with GitHub as artifact truth.

Relay Madness coordinates Claude Code on the web, OpenAI Codex cloud, and Google Jules without hosting model inference or development environments. The provider supplies the computer, GitHub supplies the durable code state, and Relay decides who works next.

The implementation design is currently under review. See [Relay Madness Design](docs/superpowers/specs/2026-08-16-relay-madness-design.md).
